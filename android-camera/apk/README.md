# Rhema Studio Cam — test build (APK)

`rhema-studio-cam.apk`: version 1.1.0.0 (smooth viewfinder, new name and icon), Android 8 or later. A test build, not a store release.
It is signed with the project's test key. Later APKs from the same place install over this one.

Install it on another Android phone:
1. On the phone, open https://github.com/thathman/rhema-studio/raw/main/android-camera/apk/rhema-studio-cam.apk
2. Allow your browser to "install unknown apps" when Android asks, then install.
3. In Rhema Studio: Production → Cameras → add a camera, then scan its "Rhema Studio Cam" QR code with the phone's camera (or paste the link into the app's Settings).

The phone must be on the same Wi-Fi as the Rhema Studio computer.
