# Live console native screenshots

These are OS screenshots of the built Rhema Studio Tauri window from the isolated macOS QA profile. The service and its content are synthetic test data.

- `live-empty-service-native.png` shows Live with no open service or rundown.
- `live-configured-service-native.png` shows a saved QA service, a private Welcome preview, and an untouched Program.

Both captures are 2784×1804 physical pixels. The configured screenshot uses the default `Main Display` output. No physical display or receiver was connected for this capture; the UI reports that no output is on a screen. The Take control remains explicit and was not pressed.
