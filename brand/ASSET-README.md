# Rhema Studio — Final Logos Only

Clean, usable logo assets — **no posters, mockups, photos, gradients, illustrations or scenic backgrounds.**

## Canonical master geometry
The large R and its top-left **bulge** are copied verbatim from the owner's supplied `Rema Studio(2).svg`; two black radio receiver curves are overlaid **inside the bulge**, replacing the previous quotation motif. No quotation marks or independent top-right waves.

All wordmarks use the SAME master icon, black square with warm-white R, without changing its geometry.

## Products
- Rhema Studio — main desktop app and operator screens.
- Rhema Studio Receiver — Google TV (plain 16:9 launcher logos, Light/Dark 320×180 to 1920×1080).
- Rhema Studio Cam — Android camera application.
- Rhema Studio Companion — mobile/remote application.

## Contents
- `01_Master_Mark/`: original-path SVG + 16–1024 pixel PNG and inverted mark.
- `02_Product_Logos/`: four horizontal standalone logo lockups, transparent-background SVG and PNG, dark/light typography.
- `03_Google_TV/`: landscape Receiver logo with solid flat background, source SVG and 320×180, 640×360, 1280×720, 1920×1080 PNG exports.
- `04_Launcher_Icons/`: Windows ICO, Android launcher/adaptive images and macOS ICNS (if available).

The product wordmarks contain editable SVG text elements with `Inter` font and fallback `Arial`; to ensure precise typographic appearance when embedding, use packaged Inter from your system or outline the text in a downstream build step. Fonts themselves are not distributed here.

This is a design asset pack, not deployed into any application repository yet. Existing licence notices remain separate.
