# Rhema Studio brand assets

This directory contains the owner's final logo pack from `Rhema_Studio_Four_Product_Logos_FINAL.zip`. The source pack's `README.md` and `ASSET-MANIFEST.json` are preserved as `ASSET-README.md` and `ASSET-MANIFEST.json`; `src/lib/brand-files.test.ts` verifies every copied pack asset against its SHA-256 manifest entry.

The master mark keeps the supplied R and its upper-left bulge, with the two radio curves inside that bulge. It has no quotation marks. Use the SVG and PNG files as supplied; do not redraw, recolor, crop, or add effects.

## Product uses

- Rhema Studio desktop app and operator screens use the master mark. macOS `.icns` and Windows `.ico` files are copied exactly from the pack.
- Rhema Studio Receiver uses its Google TV landscape logos and the light-text logo on its dark connection screen.
- Rhema Studio Cam uses the pack's Android adaptive foreground and background.
- Rhema Studio Companion uses the master mark and the Companion wordmark.

The Tauri-generated size variants not included in the pack come from the supplied 1024 px master mark. Product names, package identifiers, and the OpenBezal MIT credit are unchanged.
