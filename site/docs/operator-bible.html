OPERATOR GUIDE

Bible operator

Work with Scripture while staying inside the role and output permissions assigned by the host.

Role checks in repositoryFull browser page in development

What this role does

The Bible role can look up Bible content and operate Bible-specific actions allowed by the host, including activating a reference and stepping through verses. Preview is a separate action from activation. An activation updates the shared Bible source; each output renders that source according to its configured content and language choices.

Suggested service workflow

  1. Find the passage using a reference or search in the Bible library.
  2. Check the text and chosen translation in private Preview.
  3. Confirm the intended service moment and any output-language settings.
  4. Use the authorized Bible action when the host or service workflow calls for it.
  5. Verify the intended output separately; a successful command does not prove a receiver displayed the frame.

Language and content

Repository sources include English and Yorùbá Bible editions. The available text depends on installed editions; song lyrics and Scripture references are different content sources. Output language choices determine how subscribed outputs render a shared source. The complete bilingual journey still needs integrated acceptance.

Role boundary

The Bible role does not grant general control of scenes, cameras, OBS, output assignment, or host permissions. The host assigns and can change or revoke a paired role. Use Connected Operators for pairing and authorization details.

What is still being built: the role's complete browser workspace, bilingual edge cases, reconnect behavior, and cross-output verification. The role API does not mean a finished browser app exists.
