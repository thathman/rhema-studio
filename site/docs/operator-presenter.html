OPERATOR GUIDE

Main Presenter & Configure

Run the service from the main desk, keep actions deliberate, and use Configure access only where needed.

Presenter and Configure roles in repositoryUnified main experience in development

Presenter responsibility

The Presenter role is for day-of-service operation: following the running order, using authorized source and event controls, reviewing private Preview, and taking an item to a named output when appropriate. The Presenter should know which action changes a source and which changes a scene.

Configure responsibility

Configure provides a broader set of operational and setup actions than Presenter. It can include scene editing and configuration commands that other roles do not receive. It is still governed by the host's authoritative permissions, output scopes, and approval rules; the role is not a license to bypass safety checks.

Solo host operation

The approved product direction keeps one-computer operation viable. Volunteers, LAN desks, OBS, phones, and receivers contribute when useful but should not be prerequisites for the core service. The host remains able to pause or revoke connected access.

Production safety checklist

  • Confirm the service and current output before taking.
  • Check the private Preview and destination before a visible change.
  • Do not assume a save, approval, or successful command updated a physical receiver.
  • Keep OBS Program and congregation screens independent.
  • Use History and host status for evidence instead of inferring what happened.
