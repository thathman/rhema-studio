OPERATOR GUIDE

Editor operator

Help prepare service content and revisions while leaving production authority with the host and presenter.

Editor role in repositoryComplete operator experience in development

What this role is for

The Editor role is intended for service preparation and permitted content edits. It is useful for contributing to a service without holding the full presenter/configuration authority. The host remains the authority for service assignment, revisions, approval, and output changes.

Safe editing flow

  1. Open the service assigned by the host and confirm the revision you are editing.
  2. Make changes in Plan or a permitted private draft.
  3. Review changes before saving and note any stale-version warning.
  4. Send an approval request when a change requires host review.
  5. Leave Activate and Take actions to a role authorized for production.

What it does not authorize

Editor access does not by itself authorize a congregation Take, OBS program change, host permission edit, or camera operation. A saved edit and an approved revision do not mean the output has changed.

Still being integrated: the full Editor page, revision comparison, comments, durable draft recovery, and unified Approval Requests need end-to-end verification.
