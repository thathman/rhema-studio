Getting started

Learn what Rhema Studio is, how its connected applications fit, and how contributors can run the desktop app from source.

Development status: Rhema Studio is an active software project. This guide is not a promise that every app has a public installer or that every operator/device path is ready for a service.

What Rhema Studio is

Rhema Studio is a church-production workspace being built around one local service host. The desktop application includes preparation, content and design tools, live presentation, outputs, and host-managed operator access. It is intended to work for a solo operator, with connected team members and devices as optional contributors.

Plan, private Preview, the actual Program on an output, and execution history have different jobs. Saving preparation is not an instruction to publish a screen.

Local-first philosophy

  • The host computer is the authority for its service and production state.
  • A church can prepare and run the core service from one computer; additional operators are optional.
  • Connected operator and receiver traffic is intended to stay on the local network.
  • Optional online speech services, public streaming, external AI tools, and internet quiz access can require internet access.

Offline wording: Local-first is an approved architecture principle. It does not mean every optional integration, receiver, backup path, or WAN-off recovery scenario has passed physical acceptance.

Run the desktop app locally

For contributors, the repository README is the current source for platform packages and setup. The usual source workflow is:

git clone https://github.com/thathman/rhema-studio.git
cd rhema-studio
bun install
bun run setup:all
bun run tauri dev

You need Bun, Rust, and the platform prerequisites for Tauri. The setup script can download Bible/model data and other resources; see the repository README for current options and platform-specific steps.

This is a contributor workflow, not an installer. Check the repository's Releases page for any currently published build; this website does not claim a generally supported release is available.
