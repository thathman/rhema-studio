OPERATOR GUIDE

Stage operator

Coordinate private Stage displays and host-authorized performer cues without crossing into public output.

Structural direction approvedComplete role page and receiver acceptance pending

Private Stage responsibilities

Stage and confidence displays are separate outputs for performers and production staff. Their content can include the current item, next item, clock, countdown, or an authorized private message. A Stage view must not expose private cues to the congregation, public signage, OBS, or a recording.

Interactive desk vs. passive receiver

An interactive Stage Operator desk and a passive read-only Stage monitor are different things. The operator role can work only with recipients assigned by the host. A display should show the actual receiver and status, and the host remains able to reclaim permissions.

Safe cue handling

  • Confirm the selected recipient is assigned to this operator.
  • Keep timing reminders and requests private to the intended receiver.
  • Use host-configured priority and expiry rules; do not assume a message sent is a message displayed.
  • Never use a Stage cue as a shortcut to change a congregation scene or OBS program.
