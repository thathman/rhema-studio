Frequently asked questions

Short answers based on the current repository and approved product contracts.

Is Rhema Studio ready for production use?

Rhema Studio is in active development. Repository code and frontend captures are useful for review, but they do not establish a supported release or a completed real-service acceptance run. Check the Roadmap for known gaps.

Does Rhema require a cloud account?

The core production direction is local-first: one local host can serve a solo operator, and connected team desks are optional. Some integrations or planned collaboration features may require a network. A complete WAN-off acceptance result is not claimed.

Does saving a plan change what the congregation sees?

No. Preparing or saving a service plan should not itself change a live output. Rehearsal stays private in Preview until an operator explicitly Takes the change to a selected output. Review Preview, Program, and outputs.

Can every operator work from a browser?

No complete browser role suite is currently claimed. Host pairing, role-scoped service paths, and selected remote pages exist in code; a complete, secure, responsive operator application and real tablet/phone acceptance remain in development. See LAN browser access.

What if a paired device has no role?

It is treated as Viewer, which is read-only for production changes. The main host must assign a role before that device can use role-specific controls. Rhema recorder access is a separate host grant, not part of any role.

Does OBS recording equal Rhema service recording?

No. OBS can report or control its own stream and recording. Rhema's separate, macOS-first recorder service and host commands are in the repository, but the integrated Live recording workflow and sustained native/device acceptance are still incomplete. See Recording.

Are Google TV, Rhema Cam, and Engage supported?

Related code exists, but physical-device compatibility and end-to-end acceptance are incomplete. Engage's hosted service is not claimed as deployed. See Devices & companion apps.

Where can I find installation instructions?

The Getting Started guide describes the source checkout and development launch path. It is for contributors running from source, not a promise of a signed or production-ready installer.

Where are supported languages documented?

The repository contains English editions and Yoruba Bible content, plus output-specific language rendering code. A complete bilingual service workflow across screens and connected devices has not been accepted. See Roadmap / in development.

When documentation and behavior disagree, use current code and owner-approved contracts as evidence, report the gap, and avoid promising the unfinished behavior.
