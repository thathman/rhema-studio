OPERATOR GUIDE

Viewer operator

Follow the service and permitted status views without production control.

Viewer role in repositoryComplete read-only browser view in development

Read without changing production

The Viewer role is for observing the service state and information the host allows that desk to see. It is not a presenter or configuration role and should not expose controls that can activate sources, change scenes, or Take an output.

What a viewer should verify

  • Confirm the correct service is open.
  • Read only the output and timing information assigned to this role.
  • Report a problem through an authorized private team channel if one is enabled.
  • Ask the host to change a role if additional access is required; do not attempt to self-elevate.

Privacy and availability

Host authorization determines which service details and notices are visible. A read-only view is not evidence that a receiver is physically showing the same frame. The full responsive Viewer page and reconnect behavior remain in development.

See Connected Operators for pairing and access, and Presenter & Configure for production control.
