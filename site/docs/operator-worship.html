OPERATOR GUIDE

Worship operator

Prepare and present songs and hymns with the authority assigned to the Worship role.

Song role actions in repositoryFull browser page in development

What this role does

The Worship role can work with song content, preview lyrics, show an authorized song, and step through song sections. Hymnbook and song-library access depends on the available local content and permissions.

Suggested workflow

  1. Find the song or hymn in the library and confirm the selected item.
  2. Review the lyric sections and any English/Yorùbá text included with that content.
  3. Preview the material before requesting or taking an action.
  4. Step the song by section using the authorized controls.
  5. Check each assigned output; language and presentation can differ by output.

Language and lyrics

The repository supports song text with language labels and multiple language variants where content is supplied. This does not guarantee that every hymnbook, song, or translation is installed. The full bilingual Prepare → Preview → output journey is still being verified.

Role boundary

Worship access does not grant general scene editing, camera control, OBS control, or permission changes. The host controls role assignment and output scope. Saving or previewing lyrics should not silently take a new scene live.

Still in development: the complete connected Worship operator page, smooth handoff with Prepare and Library, and real browser/device acceptance.

See Bible operator for Scripture work, Core concepts for output behavior, and Connected Operators for host pairing.
