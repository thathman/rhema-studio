05 / AN OPEN DEVELOPMENT JOURNEY

Thoughtfully built.
Still becoming.

Rhema Studio is a work in progress. This page shares the approved product direction, not a promise that every feature is finished or available to download.

Development is happening in the project repository, with emphasis on an offline-reliable church host, secure operator roles, separate outputs, native recording and real-device acceptance.
