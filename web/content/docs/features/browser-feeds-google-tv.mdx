## Browser feeds

A **browser feed** is an output that is a web page on the church network instead of a window or an
NDI sender. It shows exactly what the output would: its looks, scene, sources, lower third and
ticker, transparent where the look is keyed.

1. Settings → Remote Control: start the HTTP listener on the network.
2. Add an output of kind **Browser Feed** (or a ready-made feed sent as a browser feed).
3. Copy its link into OBS (Browser source, 1920×1080), or scan its QR code with a TV, tablet or
   phone on the church Wi-Fi. Turn the output on.

Anyone with the link on the network can watch it; **New link** closes the old one. Its card in
Production → Screens says how it is doing: "1 page · showing the latest", "No page is showing it",
or "behind: not showing the latest" when a page has not drawn the newest frame for 3 seconds.
Video items do not play in a browser feed; a scene's looping **Video** layer does.

## Google TV (Rhema Receiver)

A Chromecast with Google TV, or another Android TV, has no web browser for this. The **Rhema
Receiver** app shows one browser feed full screen.

1. Install Rhema Receiver once from a computer: `android-tv/build.sh`, then `adb install` with the
   TV's developer options and wireless debugging on.
2. In Rhema tick **Secure page for phones (https)** (Settings → Remote Control) and start the
   listener. Rhema sends a TV only the feed's secure link.
3. Open Rhema Receiver: it shows its name, address and a six-digit code.
4. In Rhema, the browser feed's settings → **Show on a Google TV**: Rhema lists the TVs it finds
   (**Find TVs** looks again). Pick the one whose address matches the TV's screen, type the code,
   **Show on TV**. Rhema checks the code with the TV first; the code never travels over the
   network, and the link goes to the TV encrypted with this computer's certificate.

The TV keeps the feed after a restart or a power cut, keeps the last picture while Rhema or the
network is gone, and picks up again by itself. **OK** on the remote shows a new code; five wrong
codes lock it until OK is pressed. Production → Show health lists each TV with **Check TV**.
